======================================================================
5. CANONICAL IMAGE CONTRACT
======================================================================

5.1 Format input V1

Hỗ trợ:

- PNG 8-bit;
- JPEG 8-bit;
- static WebP 8-bit;
- RGB;
- RGBA;
- grayscale;
- palette image;
- CMYK JPEG với conversion có kiểm soát.

Không hỗ trợ V1:

- animated/multi-frame image;
- HEIC;
- PSD;
- TIFF/PNG 16-bit source;
- HDR/float source;
- raw camera format.


5.2 Giới hạn kích thước

Guaranteed support:

- tổng pixel <= 40 MP;
- mỗi cạnh <= 10.000 px.

Ảnh lớn hơn:

- best-effort;
- cảnh báo memory/disk;
- không được silently downscale output.


5.3 Canonical decode

CanonicalImage phải lưu:

- source_file_sha256;
- canonical_pixels_sha256;
- width;
- height;
- source format;
- original EXIF orientation;
- canonical orientation;
- RGB8 unpremultiplied pixels;
- optional source alpha;
- ICC profile bytes/hash;
- conversion flags;
- decoder version.


5.4 Orientation

- EXIF orientation được bake đúng một lần.
- Sau khi bake, canonical orientation là orientation 1.
- Mọi preview, prompt, brush, ROI và export dùng cùng canonical coordinate system.
- Export không ghi lại orientation cũ gây rotate lần hai.


5.5 ICC và CMYK

- Inference copy được color-convert sang sRGB.
- Canonical source không bị inference conversion ghi đè.
- CMYK được convert thành canonical sRGB và gắn SOURCE_CONVERTED.
- RGB integrity của CMYK/JPEG được định nghĩa trên canonical decoded pixels.
- Invalid ICC phải tạo warning, không crash.


5.6 Input đã có alpha

Mặc định:

    FINAL_ALPHA = SOURCE_ALPHA * CUTOUT_ALPHA

Không model hoặc manual operation nào được làm sống lại pixel có source alpha = 0.


======================================================================
6. HỢP ĐỒNG ALPHA VÀ COMPOSITING
======================================================================

6.1 Internal alpha

- float32;
- range logic 0.0..1.0;
- authoritative storage là disk-backed tiles;
- NaN/Inf là stage failure;
- chỉ clamp sau validation;
- không quantize sớm.


6.2 Straight alpha

PNG output phải dùng straight/unassociated alpha.

Frontend WebGL có thể premultiply để render, nhưng:

- không được lấy pixel export từ Canvas/WebGL;
- backend phải ghép RGB và alpha trực tiếp;
- test round-trip bằng decoder độc lập.


6.3 Giới hạn toán học của RGB-identical

Pixel ảnh quan sát có thể là:

    C = alpha * F + (1 - alpha) * B

Giữ C làm RGB rồi thay background mới có thể giữ lại màu nền B cũ tại tóc/glow/edge.

Vì vậy:

- MASTER_SOURCE_FAITHFUL ưu tiên RGB-identical;
- POD_READY được phép ước lượng/decontaminate edge RGB;
- app không tuyên bố hai mode cho kết quả composite giống nhau.


======================================================================
7. OUTPUT CONTRACT
======================================================================

7.1 MASTER_SOURCE_FAITHFUL

Default master.

Yêu cầu:

- output width == canonical width;
- output height == canonical height;
- output RGB == canonical RGB ở mọi pixel;
- output alpha == final alpha đã quantize;
- PNG lossless;
- không sửa edge RGB;
- không resize/trim/canvas placement.

RGB integrity:

    np.array_equal(canonical_rgb, master_rgba[:, :, :3]) == True


7.2 POD_READY

Derived output riêng, không ghi đè master.

Yêu cầu:

- PNG RGBA 8-bit;
- embedded/declared sRGB;
- straight alpha;
- color-managed conversion từ canonical ICC sang sRGB có thể đổi numeric RGB
  trên toàn ảnh nhưng phải giữ appearance trong giới hạn conversion đã test;
- edge decontamination chỉ quanh fractional/uncertain edge;
- opaque interior không bị chỉnh màu ngoài conversion ICC -> sRGB bắt buộc;
- preview trước export;
- cùng pixel dimensions mặc định;
- trim/padding/custom canvas chỉ khi user bật.

Cho phép POD_READY RGB khác master do color conversion và ở vùng xử lý viền.


7.3 ALPHA_ONLY

- grayscale PNG 16-bit;
- native dimensions;
- dùng cho QA/interchange;
- không phải authoritative project storage.


7.4 Metadata

Master giữ allowlist:

- ICC;
- PPI nếu hợp lệ;
- copyright/creator nếu user chọn.

POD_READY:

- sRGB ICC;
- PPI do export setting;
- strip GPS và metadata riêng tư;
- không lưu model/debug data trong PNG.


7.5 Export safety

- Không overwrite source.
- Collision phải hỏi hoặc tạo tên deterministic.
- Default filename:
  - <source-stem>-master.png;
  - <source-stem>-pod.png;
  - <source-stem>-alpha16.png.
- Export dùng temp file + fsync + atomic rename.
- Disk full phải giữ project và output cũ nguyên vẹn.


======================================================================
8. GENERIC DTG/DTF PREFLIGHT
======================================================================

8.1 Physical size và effective PPI

User có thể nhập:

- width/height theo inch hoặc cm;
- target PPI;
- custom transparent canvas.

Công thức:

    effective_ppi_x = placed_pixel_width / print_width_inch
    effective_ppi_y = placed_pixel_height / print_height_inch

Default guidance:

- target: 300 PPI;
- warning dưới 150 PPI;
- không tự upscale;
- không coi metadata 300 DPI là tăng chất lượng.


8.2 Preflight result

Trạng thái:

- PASS;
- WARN;
- FAIL.

FAIL dành cho:

- file corrupt;
- unsupported export;
- alpha/output invalid;
- export không thể hoàn tất.

WARN có thể override và được ghi vào report.


8.3 Preflight checks

- effective PPI;
- pixel dimensions;
- file size;
- profile/sRGB;
- alpha min/max/histogram;
- pixel alpha rất thấp nhưng khác 0;
- stray pixel và isolated speck;
- component nhỏ/rời;
- accidental opaque rectangle;
- subject bị clip bởi canvas;
- semi-transparent coverage;
- halo trên white/black/gray và custom garment colors;
- hidden RGB bất thường quanh transparent edge;
- source converted warning.


8.4 Chính sách component

- Không auto-delete component nhỏ.
- Component đáng ngờ được gắn NEEDS_REVIEW.
- User có thể keep/remove/lock từng component.
- Distressed texture và hạt grunge phải có fixture riêng.

10.1 ARTWORK

- Asset quan trọng.

- Chỉ dùng pass đã chứng minh tăng quality.
- Không có SLA 90 giây.

======================================================================
12. MODEL STACK V1
======================================================================

12.1 Base alpha proposal

Provisional default:

- BiRefNet_dynamic-matting hoặc BiRefNet-matting;
- input 1024;
- FP16 khi parity pass;
- FP32 fallback.

Fallback:

- BiRefNet_lite-matting.

MAX-only candidate:

- BiRefNet_HR-matting sau qualification.


12.2 SAM 2.1 Base+

Vai trò:

- user point/box selection;
- object membership;
- topology/hole/gap validation;
- local correction.

Không dùng SAM để:

- thay toàn bộ fractional alpha;
- tự tạo confidence probability;
- hard-fill glow/transparency.

Integration path:

1. ưu tiên implementation thuần PyTorch/Transformers + safetensors;
2. so output parity với implementation chính thức;
3. nếu parity không đạt, vendor code Meta tại pinned commit;
4. tắt runtime CUDA extension build;
5. không dùng torch.compile trong packaged V1;
6. không yêu cầu WSL, nvcc hoặc compiler trên máy user.


12.3 ViTMatte

Default:

- ViTMatte-B;
- dùng implementation Hugging Face Transformers, không phụ thuộc Detectron2;
- weights/revision/safetensors được pin trong ModelManifest;
- ROI target khoảng 512;
- native pixel crop;
- pad theo model divisor;
- overlap tile khi ROI lớn.

Fallback:

- ViTMatte-S.


12.4 Model candidate ở PHASE 0

Benchmark có thể gồm:

- BiRefNet dynamic/standard/lite/HR;
- BEN2 Base;
- FeyNoBg.

Candidate chỉ được production nếu:

- commercial POD use được phép;
- exact weights license rõ;
- quality tốt hơn trên internal holdout;
- đạt memory/latency/stability gate;
- không cần runtime remote code.

Không thêm model thứ tư vào runtime mặc định chỉ vì benchmark một metric tốt hơn.


12.5 BiRefNet integration

- Vendor/audit model code tại pinned revision.
- Không gọi trust_remote_code tại runtime.
- Dùng exact preprocessing manifest cho resize/normalize/postprocess.
- Safetensors/checksum bắt buộc trước load.
- ONNX/CoreML/TensorRT chỉ được xem xét sau V1 nếu parity và timing tốt hơn.


======================================================================
13. MODEL QUALIFICATION RULES
======================================================================

13.1 Không hard-code claim từ GPU khác

Benchmark A100/4090 không đại diện GTX 1660 Super hoặc M4.

Mọi preferred resolution/dtype phải đo trên đúng máy mục tiêu.


13.2 Windows provisional profile

BiRefNet:

- preferred 1024 FP16 nếu parity pass;
- fallback 1024 FP32 hoặc Lite FP16/FP32;
- 1280 chỉ khi measured profile pass;
- HR chỉ MAX.

SAM:

- Base+ conditional;
- FP16 hoặc FP32 đã qualify;
- không dùng BF16 trên GTX 1660 Super nếu runtime báo không support.

ViTMatte:

- Base ROI 512;
- Small fallback;
- ROI 768 chỉ khi profile pass.


13.3 macOS provisional profile

- Test từng model trên MPS FP16 và FP32.
- So parity với CPU FP32.
- Unsupported op fallback phải được log.
- Model nào crash/quality fail trên MPS dùng CPU riêng stage đó.
- Không hard-code profile theo tên M4.
- Không tắt MPS high-watermark safety.


13.4 Parity gate

Accelerated backend/dtype không được:

- giảm Boundary F1 quá 0,5 percentage point;
- tăng SAD/Gradient/Connectivity quá 2%;
- làm mất component/topology fixture;
- thay đổi source RGB.


======================================================================
14. PIPELINE VÀ FUSION RULES
======================================================================

14.1 Không average mask mù quáng

Vai trò:

    BiRefNet     -> base alpha proposal
    Color tools  -> artwork/background evidence
    SAM          -> membership/topology
    ViTMatte     -> fractional boundary/internal transparency
    Manual edit  -> user authority


14.2 Precedence

Thứ tự quyền ghi, từ cao xuống thấp:

1. Source alpha upper bound
2. Locked regions
3. Manual edits
4. Local AI refine
5. ViTMatte unknown/unlocked ROI
6. Base alpha proposal

Stage thấp hơn không được ghi đè stage cao hơn.


14.3 SAM auto prompt

Khi cần topology validation:

- tạo box từ connected component/base foreground;
- positive point từ distance-transform interior;
- negative point ngoài dilated component/box;
- kiểm tra prompt satisfaction và overlap;
- disagreement trở thành Needs Review hoặc ROI refine.

SAM candidate không tự overwrite final alpha.


14.4 Trimap

Trimap gồm:

- definite foreground;
- unknown;
- definite background.

Definite FG/BG phải dựa trên:

- consensus/evidence;
- erosion/dilation có version;
- user locks;
- source alpha constraint.

Không khóa sai chỉ dựa vào một threshold duy nhất.


14.5 Unknown width

Adaptive theo:

- image scale;
- edge hardness;
- uncertainty;
- glow/transparency;
- component size.

Không dùng một width cho mọi ảnh.


======================================================================
15. NATIVE-RESOLUTION ROI REFINEMENT
======================================================================

15.1 Nguyên tắc

Coarse 1024 mask không được upscale rồi export trực tiếp.

Phải:

    proxy proposal
      -> map về canonical coordinates
      -> discover boundary/component/uncertain region
      -> crop RGB native pixels
      -> local matting/refine
      -> write alpha vào native canvas


15.2 ROI

- Default target khoảng 512 x 512.
- Context margin 64-256 px tùy edge.
- ROI lớn được tile.
- Overlap khoảng 96-128 px hoặc adaptive.
- Pad tới model divisor, không distort aspect ratio.
- Blend alpha bằng normalized raised-cosine weights.
- Không blend RGB trong master.


15.3 Discovery ngoài coarse boundary

Phải có high-resolution discovery pass để tìm:

- component nhỏ bị proposal bỏ sót;
- line mảnh;
- outer glow;
- anti-aliased island;
- gap/hole không ổn định.


15.4 Internal transparency

Artwork có glow/mesh/transparency nội bộ:

- không hard-fill interior alpha = 1;
- dùng expanded hoặc full-object ROI khi cần;
- luôn hiển thị preview trên nền sáng/tối.


======================================================================
16. UNCERTAINTY HEURISTIC
======================================================================

16.1 Tên và ý nghĩa

Tên chính thức:

    uncertainty_heuristic

Không gọi là xác suất đúng nếu chưa calibration.


16.2 Nguồn heuristic

- output gần threshold;
- disagreement multi-scale/flip;

======================================================================
25. MEMORY PLAN
======================================================================

25.1 Windows

- Một heavy model active tại một thời điểm.
- Target stage peak VRAM <= 5,0 GiB.
- Chừa tối thiểu 768 MiB free khi có thể đo.
- Tổng app RSS mục tiêu <= 9 GiB trên máy 16 GB.
- Không dựa vào empty_cache như bảo đảm recovery.


25.2 macOS

- Unified memory profile động.
- Không hard-code M4 = một dung lượng VRAM.
- Tôn trọng recommended working set/watermark.
- Release model khi memory pressure cao.
- Warm cache không có trong V1 mặc định.


25.3 Image/mask memory

- Canonical RGB8 immutable.
- Proxy RGB nhỏ cho viewer/inference.
- Float32 alpha theo tile.
- Active ROI mới tạo float inference buffers.
- History dùng tile delta nén.


======================================================================
26. WORKER LIFECYCLE VÀ RECOVERY
======================================================================

26.1 Sequential worker

    spawn stage worker
      -> load pinned model
      -> infer
      -> validate alpha/output
      -> persist stage result
      -> exit/reuse theo safe profile


26.2 OOM recovery

Khi CUDA/MPS OOM hoặc worker fatal:

1. coordinator đánh dấu stage failed;
2. kill/reap worker;
3. giữ last valid project snapshot;
4. restart worker;
5. retry với lower profile;
6. nếu vẫn fail, đề nghị/áp dụng CPU fallback có thông báo;
7. không crash frontend.


26.3 Không silent degradation

Mỗi fallback phải ghi:

- lý do;
- model/profile cũ;
- model/profile mới;
- quality implication;
- user-visible notification.


26.4 Cancel

- User có thể cancel stage.
- Cancel không xóa last valid alpha.
- Worker được shutdown có timeout rồi terminate nếu cần.
- Project vẫn mở/editable.

32. QUALITY METRICS VÀ GATES

32.1 Metrics

Matting:

- Gradient Error;

Composite:

- edge error trên white/black/gray/red/blue background;
- halo detection sau scale/composite;

32.2 Required quality gates

Hard-edge artwork:

    Boundary F1 ±2 px >= 0.98
    unknown-band alpha MAE <= 0.015

Soft/complex artwork:

    Boundary F1 ±4 px >= 0.93
    alpha MAE <= 0.04

Component:

    recall cho component có kích thước >= 4 px >= 98%

Uncertainty:

    phát hiện >= 95% error regions có area >= 16 px
    và |alpha_error| >= 0.25


32.3 Regression rule

- Không category nào bị che bởi điểm trung bình tốt.
- Không merge release nếu category quan trọng regression vượt gate.
- Accelerated backend phải pass parity section 13.4.
